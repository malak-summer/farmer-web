# 🌱 FreshFarm - Premium Organic Farm React Website

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view in browser.

## ✨ Features

✅ **Modern React 18** + Vite (lightning fast)  
✅ **Tailwind CSS** with custom premium color palette  
✅ **Framer Motion** smooth animations & interactions  
✅ **Fully Responsive** (mobile-first design)  
✅ **Premium UI/UX** - organic shapes, gradients, blobs  
✅ **Sticky Navbar** with mobile hamburger menu  
✅ **Product Grid** with hover effects  
✅ **Social Media Section** (Instagram, Facebook, WhatsApp)  
✅ **Contact Form** (client-side validation)  
✅ **Smooth Scrolling** navigation  

## 🎨 Design

- **Colors**: Deep brown (#4E342E), Terracotta (#D84315), Cream (#FFF8E1), Olive (#6D8B74)
- **Typography**: Playfair Display (headings) + Inter (body)
- **Animations**: Fade-ins, hover transforms, parallax effects
- **Unique Elements**: Organic blobs, gradient overlays, backdrop blur

## 📱 Responsive Breakpoints

- Mobile: < 768px
- Tablet: 768px - 1024px  
- Desktop: 1024px+

## 🖼️ Images

Replace placeholder images in `/public/images/`:
```
farm.jpg (1920x1080 - hero background)
farmer.jpg (600x800 - about section)
tomatoes.jpg, strawberries.jpg, etc. (500x400 - products)
```

## 🔧 Customization

**Colors** (`tailwind.config.js`):
```js
primary: {
  brown: '#4E342E',
  terracotta: '#D84315', 
  cream: '#FFF8E1',
  olive: '#6D8B74'
}
```

**Social Links** (`Social.jsx`, `Footer.jsx`):
```js
Instagram: https://instagram.com/yourfarm
Facebook: https://facebook.com/yourfarm  
WhatsApp: https://wa.me/YOURNUMBER
```

**Contact** (`Contact.jsx`):
```js
Phone: +1 (234) 567-890
Email: hello@yourfarm.com
```

## 📦 Build for Production

```bash
npm run build
```

Output in `/dist` folder.
